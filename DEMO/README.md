# KooKid Software Blueprint และ Interactive Demo

ข้อเสนอซอฟต์แวร์สำหรับ KooKid อ้างอิง `../Doc/638811845829853633_Form-TYS(IDEA)-Proposal.docx` และการวิเคราะห์ในแชต จัดทำ 3 พฤศจิกายน 2569 เอกสารนี้เป็นข้อเสนอการออกแบบ ไม่ใช่ข้อกำหนดที่ผู้ใช้ยืนยันแล้ว

## เปิดเดโม

ดับเบิลคลิก `index.html` หรือจากโฟลเดอร์ DEMO รัน `node server.cjs` แล้วเปิด http://127.0.0.1:4173

ไม่ต้องติดตั้ง dependency ไม่ใช้ API key ไม่มีการส่งข้อมูลออกเครือข่าย สถานะอยู่ในหน่วยความจำ รีเฟรชแล้วเริ่มใหม่

## ลองใช้งาน

1. เปิดแท็บสร้างงาน ใส่โจทย์สมมติ แล้วสร้างร่างจำลอง
2. ส่งตรวจ เปลี่ยนบทบาทเป็นผู้ตรวจ เลือกงานจากคิว
3. แก้ข้อความ ตรวจ checklist ให้คะแนน แล้วอนุมัติหรือส่งกลับพร้อมเหตุผล
4. เสนอข้อความที่แก้เป็นความรู้ใหม่ ไปอนุมัติในฐานความรู้
5. ดูสรุปผลและประวัติใน Dashboard และหน้าเอกสารระบบ

เดโมแสดง workflow และ validation เบื้องต้น ไม่ใช่ระบบรักษาความปลอดภัย: การเลือกบทบาทเป็นเพียง UI ไม่มี authentication, RLS, ฐานข้อมูล, RAG, LLM, upload หรือการส่งลูกค้าจริง ข้อความตัวอย่างไม่ใช่คำแนะนำภาษี ผลร่างใช้แม่แบบคงที่ร่วมกับโจทย์ที่กรอก ไม่ได้วิเคราะห์โจทย์ด้วย AI

## ข้อสรุป

เริ่มจาก modular monolith และงานทดลอง 2 แบบ: ร่างคำตอบขอข้อมูลเพิ่มจากลูกค้า กับตรวจความครบถ้วนเอกสารตาม checklist ของสำนักงาน ต้องทดสอบกับผู้เชี่ยวชาญและสำนักงานจริงก่อนใช้ข้อมูลลูกค้า ส่วน Dashboard เป็นรายงานเบื้องต้น ไม่ใช้คะแนนเฉลี่ยตัดสินว่าส่งงานได้โดยไม่ตรวจ
